# Identidade Desata

Arquivos de referência da marca, fora do pacote do programa. O programa usa os arquivos de
`src/prodata/marcas/desata/` (símbolo, ícone, fontes e `marca.toml`).

- `desata-horizontal.png`: logo principal (símbolo + nome), fundo transparente.
- `desata-horizontal-fundo-escuro.png`: o mesmo para fundos escuros (nó em branco).
- `desata-monocromatica.png`: versão monocromática.
- `desata-simbolo.png`: só o símbolo.

Paleta principal: Petróleo `#003F46` (institucional), Teal `#007E7D` (apoio), Verde fluxo `#21C7A4` (acento).
Tipografia: Manrope (títulos), Inter (texto), JetBrains Mono (SQL e fórmulas).
Slogan: "Desate a complexidade. Conecte possibilidades."
